# Outils de diagnostic

Les étudiants utilisent uniquement les scripts `check-environment.bat` (Windows) ou `check-environment.sh` (Linux/macOS). Ils vérifient sans modifier la machine la disponibilité de Java, du compilateur Java et, à titre indicatif, de Maven.

Les scripts `package-kits.ps1` et `package-kits.sh` sont réservés à l'enseignant ou à la personne qui prépare la distribution. Les archives générées n'embarquent ni le dossier `teacher/` ni ces scripts de fabrication.
