# Guide d'Orientation : Choisir mon Parcours

Bienvenue dans l'atelier **Abyss Explorer** !
Ce document vous aide à vous positionner en **3 à 5 minutes** sur le parcours le plus adapté à votre profil.

---

## 1. Auto-Évaluation Rapide (9 Questions)

Répondez honnêtement par **OUI** ou **NON** :

1. **Classes & Attributs** : Savez-vous créer une classe Java avec des attributs privés et un constructeur ?
2. **Encapsulation** : Comprenez-vous pourquoi `private int battery;` est préférable à `public int battery;` ?
3. **Collections** : Savez-vous manipuler une `List<Drone>` (ajouter, parcourir avec une boucle) ?
4. **Énumérations** : Avez-vous déjà créé et manipulé une `enum` en Java ?
5. **Héritage** : Pouvez-vous expliquer la différence entre `extends` et `implements` ?
6. **Interfaces** : Avez-vous déjà conçu et implémenté une interface Java dans un projet ?
7. **Tests Unitaires** : Avez-vous déjà écrit un test avec JUnit pour valider une méthode ?
8. **Polymorphisme** : Savez-vous expliquer concrètement ce qu'apporte le polymorphisme ?
9. **Architecture** : Comprenez-vous pourquoi la logique métier ne doit pas être écrite directement dans la méthode `main` ?

---

## 2. Recommandation

* **Vous avez moins de 6 "OUI"** $\rightarrow$ **Parcours Essentiel**
  * *Objectif* : Consolider les fondamentaux de la POO en Java (classes, encapsulation, constructeurs, listes, enums, menu console, règles métier de base).
  * *Emplacement* : Rendez-vous dans `student/essentiel/README.md`.
  * *Starter* : Travaillez dans `student/essentiel/starter/`.

* **Vous avez 6 "OUI" ou plus** $\rightarrow$ **Parcours Conception Objet**
  * *Objectif* : Concevoir un domaine métier riche et évolutif (composition, interfaces, objets résultats, gestion d'invariants, tests JUnit, sélection algorithmique).
  * *Emplacement* : Rendez-vous dans `student/conception-objet/README.md`.
  * *Starter* : Travaillez dans `student/conception-objet/starter/`.

---

## 3. Règle Importante : Des Passerelles Flexibles

* **Ce choix n'est pas figé** : Le parcours Essentiel n'est absolument pas un parcours « dégradé ». C'est une trajectoire ciblée pour bâtir un code propre, robuste et sans sur-complexité.
* **Évolution en cours de journée** : Si vous terminez rapidement le socle du parcours Essentiel, le document `student/essentiel/POUR_ALLER_PLUS_LOIN.md` vous permet d'aborder progressivement les règles avancées (capacités, charge, maintenance, sélection automatique).
* **Consultez les aides** : En cas de doute syntaxique ou conceptuel, les fiches `docs/AIDE_MEMOIRE_JAVA.md` et `docs/AIDE_MEMOIRE_POO.md` sont à votre entière disposition.
