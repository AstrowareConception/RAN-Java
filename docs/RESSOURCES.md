# Ressources Externes et Documentation

Sélection de ressources fiables et officielles pour approfondir la programmation Java et la conception logicielle.

---

## 1. Documentation Officielle Java (Oracle & OpenJDK)

* **Portail d'apprentissage Java officiel**  
  URL : [https://dev.java/learn/](https://dev.java/learn/)  
  *Utilité* : Tutoriels modernes et complets couvrant la syntaxe, l'orienté objet, les records et les lambdas.  
  *Parcours* : Essentiel & Conception objet.

* **Documentation de l'API Java 21 LTS (Javadoc)**  
  URL : [https://docs.oracle.com/en/java/javase/21/docs/api/](https://docs.oracle.com/en/java/javase/21/docs/api/)  
  *Utilité* : Référence complète des classes standards du JDK (`java.lang`, `java.util`, etc.).  
  *Parcours* : Essentiel & Conception objet.

* **Les Collections en Java (dev.java)**  
  URL : [https://dev.java/learn/api/collections-framework/](https://dev.java/learn/api/collections-framework/)  
  *Utilité* : Guide complet sur `List`, `Set`, `Map` et leurs implémentations (`ArrayList`, `HashSet`).  
  *Parcours* : Essentiel & Conception objet.

* **Les Types Énumérés (`enum`)**  
  URL : [https://dev.java/learn/classes-objects/enums/](https://dev.java/learn/classes-objects/enums/)  
  *Utilité* : Définition, utilisation et méthodes avancées des énumérations en Java.  
  *Parcours* : Essentiel & Conception objet.

* **Héritage et Polymorphisme**  
  URL : [https://dev.java/learn/classes-objects/inheritance/](https://dev.java/learn/classes-objects/inheritance/)  
  *Utilité* : Comprendre les mécanismes d'extension de classes et de redéfinition de méthodes (`@Override`).  
  *Parcours* : Conception objet.

* **Les Interfaces en Java**  
  URL : [https://dev.java/learn/classes-objects/interfaces/](https://dev.java/learn/classes-objects/interfaces/)  
  *Utilité* : Spécification de contrats d'interface et implémentations multiples.  
  *Parcours* : Conception objet.

* **L'API Stream (dev.java)**  
  URL : [https://dev.java/learn/api/streams/](https://dev.java/learn/api/streams/)  
  *Utilité* : Traitement déclaratif des collections (filtrage, transformation, réduction).  
  *Parcours* : Conception objet.

* **La classe `Optional` (Oracle Javadoc)**  
  URL : [https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Optional.html](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Optional.html)  
  *Utilité* : Gestion propre de l'absence de valeur sans `null`.  
  *Parcours* : Conception objet.

  *Parcours* : Conception objet.

* **Guide Utilisateur JUnit 5 (Jupiter)**
